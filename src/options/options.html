Useful Subtitle 設定

Prime Video・YouTube の字幕の単語・フレーズをクリックすると Claude が日本語で解説します。

YouTube は通常の動画ページで英語字幕を ON にしてください。Language Reactor など他の字幕拡張は OFF を推奨します。自動字幕の更新中は翻訳が遅れることがあります。

Claude Code をインストールし、利用する Claude Pro アカウントでログインしてください。接続プログラムの登録は初回のみ必要です。

拡張機能 ID:

useful-subtitle のフォルダ（package.json がある場所）をターミナルで開き、上のコマンドを実行してください。登録後に拡張機能を再読み込みし、接続テストを実行します。

Claude / Claude Code と利用上限を共有します。月額内で使うには、Claude アカウントの「追加使用」を OFF にしてください。CLI のプラン名表示だけでは契約・課金設定を確認できません。

起動の待ち時間が加わり、全行のリアルタイム和訳は保証できません。必要に応じて下の「字幕一文の日本語訳も併記」を OFF にしてください。接続処理はローカルで動き、翻訳・解説のために字幕や選択した語句を Claude へ送信します。API への自動切り替えはありません。

console.anthropic.com で取得できます。キーはこのブラウザ内にのみ保存され、AI への問い合わせ以外で外部に送信されることはありません。
既定: claude-haiku-5-5（高速・低コスト）

自動翻訳を OFF にすると、新しい自動翻訳の送信を停止します。拡張機能を OFF にすると、翻訳・解説の新しい送信を停止します。表示への反映や ON に戻した後の再開には、開いている動画タブの再読み込みが必要な場合があります。接続テストは OFF の状態でも使えます。
