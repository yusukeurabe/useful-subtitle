# 字幕履歴の行ホバーで和訳＋解説を行の下に表示 設計

**日付:** 2026-11-22
**ブランチ:** `feat/transcript-row-hover-meaning`

## ゴール

右側の「字幕の履歴」パネルで、行の**単語以外の場所**に **700ms** カーソルを置き続けると、
その行の英文の**和訳＋かんたんな解説**を**英文のすぐ下に差し込んで表示**する。
一度出した表示は**出したまま残す**（読み返し用）。

```
 I've been meaning to call you.      ← 余白・語間に 0.7 秒
 ずっと電話しようと思ってたんだ         ← 和訳（黄色）
 have been meaning to は「ずっと…」    ← 解説（小さめ・灰色）
```

## 既存機能との関係

- **単語の上**は従来どおり単語ポップアップ（上段＝単語、下段＝字幕の和訳＋解説）。変更しない。
- **行クリック＝シーク**（`onSeek`）も従来どおり。差し込んだ表示をクリックしてもシークする。
- AI 呼び出しは既存の `onExplain(sentence)`（＝ `explainSentence`）を再利用する。
  単語ポップアップの下段と同じ要求なので**キャッシュを共有**し、単語ホバー済みの行なら即表示・追加費用なし。
- **新しい設定項目・メッセージ種別は追加しない**。`onExplain` 未指定なら本機能も無効。

## 動作

- 発火のきっかけは行内の `mousemove`（`mouseover` ではない）。再生中の自動スクロールで止まったカーソルの下を
  行が流れると、マウスを動かさなくてもブラウザが `mouseover` を出し、AI 呼び出しが連発するため。
- 「単語以外」の判定: 行内の `mousemove` の対象が `.word` span（の内側）でなければ単語以外とみなす。
  英文の語間（テキストノード → 対象は `.en`）、行の padding、短い行の右側の空き、和訳欄・差し込み表示の上が該当。
- 単語以外でマウスを動かす → その行のドウェルタイマー（700ms）を開始。同じ行の中で動かし続けても
  **張り直さない**（最初に動かした時点から 700ms で発火）。
- `.word` に入る／行から `mouseleave` → その行のドウェルを取り消す。
- ドウェル発火 → 英文の下に表示ブロックを作り「Thinking…」→ `onExplain(英文)` を呼ぶ。
  - 成功: 和訳（`.rm-trans`、黄色）＋解説（`.rm-expl`、小さめ灰色）に差し替える。
  - エラー: 赤字（`.err`）で表示。**行を一度出て（`mouseleave`）戻ってから**マウスを動かすと再取得する。
    行の中にいる間は動かしても再要求しない（エラーを読む間に 700ms ごとに AI を呼ばないため）。
- 既に成功表示済み、または取得中の行ではドウェル自体を始めない（再ホバーしても何もしない）。
- **同じ文の同時要求は共有する**: 単語ポップアップ下段と行の差し込み表示が同じ英文を同時に求めた場合、
  取得中の要求を共有して `onExplain` は1回だけ呼ぶ（background のキャッシュは完了後にしか効かないため）。
  要求が決着したら共有を外す。
- **和訳の重複回避**: デュアル字幕で行の `.ja` に既に和訳が入っている場合、和訳は出さず**解説だけ**を出す。
  （応答到着時点の `.ja` の内容で判定する。応答の後に `.ja` が届いた場合は CSS
  `.row .ja:not(:empty) ~ .row-meaning .rm-trans { display: none; }` で差し込んだ和訳を隠す）
- ドウェルは単語ポップアップのタイマーとは独立。両者が同時に動いても干渉しない。

## 履歴パネルのホバーで一時停止（ユーザー要望で追加）

- 既存設定「字幕にカーソルを乗せている間は一時停止」（`pauseOnSubtitleHover`）を
  「字幕・字幕履歴に…」へ広げ、1つのチェックで両方を切り替える。仕組みも字幕ホバーと同じ `hoverPause` を使う
  （入ったら再生中なら止め、出たら自分が止めた場合だけ再開）。
- パネル（`.panel`）の `mouseenter` で `onHoverStart`、`mouseleave` で `onHoverEnd({ resume: true })`。
- 単語ポップアップはパネルの外（左）に開くので、開いている間はパネルを出てもホバー継続。
  ポップアップが閉じた時点でパネル外なら `onHoverEnd({ resume: true })`。
- ✕・非表示でカーソルの下からパネルが消えたときも終了を通知する（mouseleave が来ないことがあるため。二重には通知しない）。
- `clear()`（作品切り替え）・`destroy()` でポップアップを閉じたときは `resume: false`（再開しない）。
- 狙い: 読んでいる間は履歴が流れず、止まったカーソルの下を行が通り過ぎることもない。
  ただし行クリック（シーク）は再生を始めるので、上の `mousemove` 起点の対策も併せて残す。

## 古い応答の破棄・後始末

- 行ごとに世代番号を持ち、次の場合に増やして表示ブロックを除去・ドウェルを取り消す:
  - 行の英文が更新されたとき（YouTube のローリング字幕で `append` が同じ id を更新）
  - `clear()` で履歴を全消去したとき（全行）
- 応答到着時に世代が変わっていれば破棄する。

## テスト

- 単語以外（`.en` の語間・行）に 700ms 置くと `onExplain` が英文で呼ばれ、和訳と解説が行の下に出る。
- `.word` の上に置いているだけでは行の表示は出ない（単語ポップアップのみ）。
- 700ms 前に行を離れる／単語へ移ると `onExplain` は呼ばれない。
- 表示は行から離れても残る。成功済みの行へ再ホバーしても再要求しない。
- エラーは赤字で出て、行を出て戻ってから再要求する。行の中で動かし続けても再要求しない。
- 単語ポップアップと行の表示が同じ文を同時に求めても `onExplain` は1回だけ。
- `.ja` に和訳がある行では解説だけを出す。
- 英文更新・`clear()` で表示が消え、遅れて届いた応答は捨てられる。
- `onExplain` 未指定なら何も出ない。行クリックでのシークは引き続き動く。
