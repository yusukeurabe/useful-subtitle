# 字幕履歴の行ホバーで和訳＋解説を行の下に表示 設計

**日付:** 2026-11-22
**ブランチ:** `feat/transcript-row-hover-meaning`

## ゴール

右側の「字幕の履歴」パネルで、行の**単語以外の場所**に **500ms** カーソルを置き続けると、
その行の英文の**和訳＋かんたんな解説**を**英文のすぐ下に差し込んで表示**する。
一度出した表示は**出したまま残す**（読み返し用）。

```
 I've been meaning to call you.      ← 余白・語間に 0.5 秒
 ずっと電話しようと思ってたんだ         ← 和訳（黄色）
 have been meaning to は「ずっと…」    ← 解説（小さめ・灰色）
```

## 既存機能との関係

- **単語の上**は従来どおり単語ポップアップ（上段＝単語、下段＝字幕の和訳＋解説）。変更しない。
- **行クリック＝シーク**（`onSeek`）も従来どおり。差し込んだ表示をクリックしてもシークする。
- AI 呼び出しは既存の `onExplain(sentence)`（＝ `explainSentence`）を再利用する。
  単語ポップアップの下段と同じ要求なので**キャッシュを共有**し、単語ホバー済みの行なら即表示・追加費用なし。
- **新しい設定項目・メッセージ種別は追加しない**。`onExplain` 未指定なら本機能も無効。

## 動作

- 「単語以外」の判定: 行内の `mouseover` の対象が `.word` span（の内側）でなければ単語以外とみなす。
  英文の語間（テキストノード → 対象は `.en`）、行の padding、短い行の右側の空き、和訳欄・差し込み表示の上が該当。
- 単語以外に入る → その行のドウェルタイマー（500ms）を開始（既に同じ行で待機中なら張り直さない）。
- `.word` に入る／行から `mouseleave` → その行のドウェルを取り消す。
- ドウェル発火 → 英文の下に表示ブロックを作り「Thinking…」→ `onExplain(英文)` を呼ぶ。
  - 成功: 和訳（`.rm-trans`、黄色）＋解説（`.rm-expl`、小さめ灰色）に差し替える。
  - エラー: 赤字（`.err`）で表示。**同じ行へ再ホバーすれば再取得**する。
- 既に成功表示済み、または取得中の行では再ホバーしても何もしない。
- **和訳の重複回避**: デュアル字幕で行の `.ja` に既に和訳が入っている場合、和訳は出さず**解説だけ**を出す。
  （応答到着時点の `.ja` の内容で判定する）
- ドウェルは単語ポップアップのタイマーとは独立。両者が同時に動いても干渉しない。

## 古い応答の破棄・後始末

- 行ごとに世代番号を持ち、次の場合に増やして表示ブロックを除去・ドウェルを取り消す:
  - 行の英文が更新されたとき（YouTube のローリング字幕で `append` が同じ id を更新）
  - `clear()` で履歴を全消去したとき（全行）
- 応答到着時に世代が変わっていれば破棄する。

## 見た目

- 差し込みブロック `.row-meaning`（`.ja` の下、`margin-top: 4px`）。
  - `.rm-trans`: `.ja` と同じ 12px・黄色 `#ffe08a`。
  - `.rm-expl`: 11.5px・`#c8c8c8`・行間 1.45。
  - ローディングは既存の `loading` の色、エラーは既存の `.err` の色に揃える。

## テスト

- 単語以外（`.en` の語間・行）に 500ms 置くと `onExplain` が英文で呼ばれ、和訳と解説が行の下に出る。
- `.word` の上に置いているだけでは行の表示は出ない（単語ポップアップのみ）。
- 500ms 前に行を離れる／単語へ移ると `onExplain` は呼ばれない。
- 表示は行から離れても残る。成功済みの行へ再ホバーしても再要求しない。
- エラーは赤字で出て、再ホバーで再要求する。
- `.ja` に和訳がある行では解説だけを出す。
- 英文更新・`clear()` で表示が消え、遅れて届いた応答は捨てられる。
- `onExplain` 未指定なら何も出ない。行クリックでのシークは引き続き動く。
